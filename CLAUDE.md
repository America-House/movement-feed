## Claude Code specifics

- Assume the person you are helping may know nothing about software. Explain each step in plain words before you take it, and teach the reason behind each rule as it comes up.
- This repository is public. Before every commit, check the diff for anything private.
- Work on a branch and open a **draft** pull request with `gh pr create --draft`, filling in `.github/pull_request_template.md`. Never push to `main`, never merge, and never edit `feed.json` unless the owner asks.
- Ask before any destructive, irreversible or costly action, and before touching settings or other people's branches.
