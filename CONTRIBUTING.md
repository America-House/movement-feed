# Contributing to the movement feed

This guide assumes you have never worked on software before. Read [AGENTS.md](AGENTS.md) too; if the two disagree, AGENTS.md wins, so tell an owner and the guide can be fixed.

**This repository is public.** Everything you commit, including its history, is visible to anyone.

## Words you will see

- **Repository (repo):** the folder of files and its full history, stored on GitHub.
- **`main`:** the official version. The live America.co site reads `feed.json` from it directly.
- **Branch:** your own copy where you can make changes safely.
- **Commit:** a saved snapshot of your changes, with a short message.
- **Pull request (PR):** a request to merge your branch into `main`. Someone else reviews it first.

## What you can change here

Documentation (README, this guide, AGENTS.md). `feed.json` is generated by the owner's publisher in the America.co website repository; do not edit it by hand. To change what the feed contains, propose the change in the website repository, where it can be tested.

## Option A: edit in the browser

1. Open the file on GitHub and click the pencil (**Edit**) icon.
2. Make the change.
3. Click **Commit changes** (or **Propose changes**), choose to create a new branch, and name it, for example `docs/explain-fields`. If you do not have write access, GitHub first makes your own copy of the repository (a **fork**) and puts the branch there. That is normal.
4. Fill in the pull request template and click **Create pull request**. Do not merge it yourself.

## Option B: work on your computer

1. Install [Git](https://git-scm.com/downloads) and the [GitHub CLI](https://cli.github.com/), then run `gh auth login`.
2. Get the code and make a branch. Most contributors cannot push to this repository directly, so make your own copy (a **fork**) and work from that:

   ```sh
   gh repo fork America-House/movement-feed --clone
   cd movement-feed
   git switch -c docs/short-description
   ```

   If you do have write access, `gh repo clone America-House/movement-feed` works too.

3. Make your change.
4. Check it:

   ```sh
   python3 -m json.tool feed.json > /dev/null && echo "feed.json is valid"
   git status
   git diff
   ```

   Make sure the diff contains nothing private: no keys, passwords, personal data or unapproved numbers.

5. Commit with one short sentence in the imperative, then push your branch to your fork (never `main`):

   ```sh
   git add <the files you changed>
   git commit -m "Explain the feed fields in the README"
   git push -u origin docs/short-description
   ```

6. Open the pull request against `America-House/movement-feed` with `gh pr create --draft`, or click **Compare & pull request** on GitHub. Fill in What, Why, How tested, Risk and Rollback. When it is ready, click **Ready for review** and ask someone else to review it.

## Using an AI assistant

Claude Code reads [CLAUDE.md](CLAUDE.md) and other agents read [AGENTS.md](AGENTS.md). They are told to follow these steps and explain what they are doing. If an assistant suggests pushing to `main`, editing `feed.json`, committing a secret or deleting something, stop and ask a maintainer.
